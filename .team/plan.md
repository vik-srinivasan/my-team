# Plan — Rename Viktown → my-team

## Goals

1. Rename "Viktown" → "my-team" everywhere in source, configs, and docs.
2. Update landing page header to `my-team: Multi-Agent…` and add a WIP indicator to the dashboard-like landing page elements.
3. Update the session-branch prefix in captain code so future sessions create branches under `my-team/<id>` instead of `viktown/<id>`.
4. Leave the GitHub repo rename and local-directory rename as post-merge user actions (commands provided at session end).

## Casing convention

| Context | Form |
|---|---|
| npm scope, branch prefix, package names, lowercase prose | `my-team` |
| Prose brand mentions (CLI descriptions, log lines, doc headings) | `my-team` |
| All-caps (SVG) | `MY-TEAM` |
| Error class | `MyTeamError` |
| Internal constant `VIKTOWN_AGENTS_DIR` | `MY_TEAM_AGENTS_DIR` |

## Approach — 3 engineers in parallel by file area

Areas are non-overlapping so engineers can run concurrently.

### Engineer A — `packages/` + root configs

- Update `name` and workspace `dependencies` in every `package.json` under `packages/*`, `apps/landing/`, and root.
- Update `vercel.json` `buildCommand`.
- Update `setup.sh` `pnpm --filter` invocations.
- Rewrite all `@viktown/shared` imports → `@my-team/shared` in TS files.
- Rename `ViktownError` class + subclasses + `this.name` literal + import sites → `MyTeamError`.
- Update `VIKTOWN_AGENTS_DIR` → `MY_TEAM_AGENTS_DIR`.
- Update branch prefix in `worktree.ts` and matching test assertions/cleanup commands.
- Update CLI description strings, wrapper log strings, fallback remote ID, page title.
- Run `pnpm install` to regenerate `pnpm-lock.yaml`.
- Run `pnpm -r build` and `pnpm -r test` to verify.

### Engineer B — `apps/landing/`

- Hero `<h1>`: change to `my-team: Multi-Agent orchestration` / `for Claude Code.` (preserve existing gradient styling).
- All `GITHUB_URL` constants in landing components → `https://github.com/vik-srinivasan/my-team`.
- Quickstart clone command → `my-team.git`.
- HowItWorks terminal lines `[viktown]` → `[my-team]`.
- Architecture SVG `VIKTOWN` text → `MY-TEAM`.
- Footer brand text → `my-team`.
- `layout.tsx` metadata: title, description, OG, `metadataBase` → `my-team` (use `https://my-team.dev`).
- **Add WIP indicator** to the Hero right-panel `AgentFlow` widget (small "WIP" pill near the "live" indicator).
- **Add WIP indicator** to the Architecture diagram's "Web UI" box (small "WIP" sub-label).
- Run `pnpm --filter @my-team/landing build` to verify.

### Engineer C — docs + agent prompts

- Update `SPEC.md`, `README.md`, `CLAUDE.md`, `SETUP.md`, `implementation_plan.md`, `tasks.md`: `Viktown`/`viktown` → `my-team`; hardcoded repo URLs → `my-team`; suggested paths like `~/.viktown` → `~/.my-team`.
- Update `agent-prompts/*.md` identity lines (captain, scout, engineer, tester, reviewer, git).
- Do NOT edit `.claude/agents/` (regenerated by wrapper at session-create).
- Do NOT edit any `.team/` files under past sessions.
